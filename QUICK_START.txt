=======================================================================
                          QUICK START
=======================================================================

ONE LINE INSTALL

   curl -fsSL https://raw.githubusercontent.com/bhd-cap/netconfig/main/install.sh | bash

Or, from inside a checkout of this repository:

   ./install.sh

The installer does everything: checks Docker, generates secrets, builds
the images, starts the stack, waits for the API to report healthy, runs
migrations and creates the admin user.

-----------------------------------------------------------------------

OPEN

   Web UI      http://localhost:3000
   API docs    http://localhost:8000/docs

LOG IN

   Username    admin
   Password    changeme      <- temporary, change after first login

-----------------------------------------------------------------------

KEEP A COPY OF .env

   ENCRYPTION_KEY in .env decrypts every stored device password. If it is
   lost, saved credentials cannot be recovered.

-----------------------------------------------------------------------

INSTALLER OPTIONS

   INSTALL_DIR=/opt/netconfig    where to install (default ./netconfig)
   ADMIN_PASSWORD=...            admin password (default changeme)
   FRONTEND_PORT=3000            published UI port
   BACKEND_PORT=8000             published API port
   WITH_MONITORING=true          also start Flower on :5555
   SKIP_BUILD=true               reuse existing images

   Example:
      INSTALL_DIR=/opt/netconfig WITH_MONITORING=true ./install.sh

-----------------------------------------------------------------------

MANAGING THE STACK

   Status              docker compose ps
   Follow logs         docker compose logs -f
   Follow one service  docker compose logs -f backend
   Restart a service   docker compose restart backend
   Stop everything     docker compose down
   Stop and wipe data  docker compose down -v      (deletes backups!)

   Task monitor        docker compose --profile monitoring up -d
   TLS proxy on :80    docker compose --profile proxy up -d

-----------------------------------------------------------------------

RE-RUNNING THE INSTALLER

   Safe. It keeps the existing .env and its secrets, rebuilds, and resets
   the admin password back to ADMIN_PASSWORD.

-----------------------------------------------------------------------

IF SOMETHING IS WRONG

   Docker not reachable
      Start Docker Desktop. In WSL, enable integration for the distro
      under Settings -> Resources -> WSL Integration.

   Port already in use
      FRONTEND_PORT=3100 BACKEND_PORT=8100 ./install.sh

   API never becomes healthy
      docker compose logs backend
      docker compose ps

   Forgot the admin password
      docker compose exec backend python init_db.py --reset-admin-password
